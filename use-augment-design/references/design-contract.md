# Design Contract

## Scope

This package defines how Augment-branded work looks, feels, and sounds. It does not define what Augment sells, product positioning, product names, campaign claims, or use cases. Those belong to the consuming surface.

## Posture

Augment should read as calm infrastructure: precise, consequential, source-aware, and tactile. The design should feel exact before it feels expressive.

## Non-Negotiables

- Matter SQ is the branded typeface.
- Official logo SVG files from `assets/logo/` are the only identity artwork.
- Token values in `tokens/*.css` are the source for color, type, spacing, radius, shadow, glow, grain, and motion.
- Sentence case is the default for headings, actions, labels, and navigation.
- Small all-caps type labels things; it does not garnish headings.
- Chromatic color is signal, atmosphere, or artwork. It is not decoration.
- No emoji, inflated AI language, or invented brand primitives.
- Customer names stay private unless the user explicitly approves them for the surface.

## Brand Spine

- Burgundy is the primary brand spine.
- Plum supports burgundy and should recede behind it.
- Cool ink neutrals carry text and chrome.
- Bone neutrals are warm paper canvases for document, report, and calm marketing contexts.
- Artwork hues belong inside swirl, atmosphere, or explicit signal.

## Product Boundary

This package can guide a surface that already has a purpose. It must not invent that purpose. Do not add recipes, starter pages, fake product dashboards, fake customer scenarios, or demo flows that imply what Augment is for.
