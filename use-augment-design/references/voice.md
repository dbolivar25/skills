# Voice

Augment copy is concrete, calm, source-aware, and free of hype.

## Rules

- Sentence case everywhere.
- Speak to the user as "you". Refer to the product as "Augment" or "the platform".
- Avoid "we" marketing language in product surfaces.
- Use short concrete verbs: Run, Apply, Review, Open, Revert, Retry.
- Claims need a source, number, context, record, or consequence when space allows.
- Error states state the fact, consequence, and recovery path.
- Empty states name the missing object and the next available move.
- Do not use emoji or exclamation points.
- Do not use empty AI language: seamless, robust, world-class, revolutionary, unlock, supercharge, magic, autonomous, game-changing, next-gen.
- Do not call the product an agent, copilot, or AI SDR unless that is explicit product truth in the target app.

## Patterns

Action labels:

- Good: Run, Apply, Review, Open, Retry.
- Weak: Get started, Unlock insights, Supercharge workflow.

Errors:

- Format: fact, consequence, recovery.
- Example: Couldn't load the item. Your current view is unchanged. Retry.

Empty states:

- Format: missing object, next move.
- Example: No item selected. Choose an item to continue.

Notifications:

- Keep them factual and bounded.
- Example: Changes saved. Review remains available.

## Headings

Let the heading carry the point. Do not add a decorative eyebrow above it. If context is necessary, make it a real label, tab, breadcrumb, status, or body sentence.
