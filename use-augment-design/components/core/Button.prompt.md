Primary action control — sentence-case label, calm hover, small press scale, visible focus ring. Use for any user action.

```jsx
<Button variant="primary" size="md" onClick={save}>Save changes</Button>
```

Variants: `primary` (burgundy fill), `secondary` (white + hairline border), `ghost` (transparent), `danger` (red). Sizes: `sm` 32 / `md` 40 / `lg` 48. Props: `disabled`, `loading` (spinner), `iconLeft` / `iconRight`, `fullWidth`. Keep labels short and concrete ("Run", "Apply", "Review").
