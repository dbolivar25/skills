# Make work reviewable

Read the [core](core.md) and PR guidance when applicable. Acquire the actual work,
prior state, intent and evidence, using understand-change when a grounded map is
needed. Pin a local comparison or live PR explicitly; do not call local context
live. Reuse a current review map supplied by another task owner.

Apply the core to construct the account around the reader's questions. Recover
any named source gap and reassess affected claims. A review guide for non-code
work does not select code-review axes or GitHub operations.

Return the draft or write the requested artifact. Before a live PR update, follow
[PR operations](../github-evidence/references/pr-operations.md), recheck the target,
refresh affected copy and perform only the requested action. Read back the
published result. Drafting, judgment and publication remain separate outcomes.
