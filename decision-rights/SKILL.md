# Decision rights

Read the [core](core.md). Recover the actual request, applicable instructions,
authority, prior settlement and the concrete concern. Resolve the core's VERIFY
needs using available evidence in proportion to the consequence of the action.
Do not make the user repeat established scope or obtainable facts.

For ASK, present the owner decision and material alternatives once. Carry an
answer back into the core; time or repeated argument is not an answer. For
BOUNDARY or HANDOFF, explain the actual limitation and permitted next path.
For PROCEED, return the settlement to the caller and continue the already
authorized task. Do not invent a new effect merely to demonstrate compliance.

Preserve the settlement in task context, or pass it to an existing Steward work
item when one is active. This skill does not open durable runtime or require an
independent reviewer. Reopen only when the governing premise actually changes.
