# Critique a candidate

Read the [core](core.md). Pin the candidate and purpose, gather governing evidence,
and establish the requested axes. Resolve discoverable context rather than asking
the user to recreate it. Preserve version and coverage limits.

When independent critique is requested, use an agent that did not author the
candidate and give it the core, criteria and required evidence. Report when that
independence is unavailable; a self-check cannot satisfy an independent gate.
Ordinary critique does not require a new agent. When a parent already assigned an
independent reviewer, apply the core there without dispatching another reviewer.

Resolve concrete evidence needs from the core and re-evaluate affected findings.
Return one assessment with checked scope, weaknesses and limits. Do not rewrite
the candidate, schedule the parent's team, record acceptance or publish unless
the task separately requests that effect. Steward's adapter owns its phase axes,
status mapping and acceptance timing.
