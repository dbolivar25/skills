# Augment design

Read the [core](core.md). For a brand-resource request, return the relevant official
assets, token values or law without starting a build. If invocation has no task,
ask what surface or resource is needed before loading the full system.

For a surface, follow [design operations](operations.md): establish the moment,
select the branch, load composition/foundations and materialize every token and
asset the core needs. Apply its judgment before building. Copy official assets
into the target project, use the existing tokens and utilities, and preserve the
selected surface's floor and facets. Do not invent positioning or customer-name
permission.

Apply the brand voice pass to every authored string. Render every relevant page
and state at full and thumbnail size, then run the existing audit. Feed renders,
copy and audit receipts into the core; resolve findings or record the concrete
reason an audit finding is acceptable. Nothing ships unrendered.

Return the requested artifact or resource and the actual verification. A brand
judgment does not authorize publication, and a clean automated audit does not
replace visual or prose inspection.
