# Steward core

Read the [core/shell contract](../contracts/core-shell.md).

**Inputs:** Owner Intent, current State/Record revision and next projection, governing premises, proposed commitments/reports, review evidence and actual stage receipts.

Preserve Aim and Why as the basis for the next coherent move. Use supplied Rules,
Non-goals, Done, support and current runtime projection. Runtime contracts remain
the source of truth for event validity and derived state; this core does not
reimplement their reducer or fabricate a state transition.

First judge whether intent, a premise, authority, coordination or separate outcome
proof must survive changing work. A bounded task without that need requires no
mission machinery. Return the ordinary path rather than inventing a durable need.

Compare each proposed commitment with current purpose and support. Preserve open
owner choices and viable alternatives until the next real commitment requires
them. Surface unsupported or contradicted premises and the dependent work they
affect; do not discard unaffected support when one premise changes.

Use [critique](../critique/core.md) with the supplied phase criteria for deliberate
falsification; accept its assessed evidence, not the author's confidence. Required
independence must be established by actual actor provenance. The shell owns the
phase-review adapter, independent assignments and recording acceptance.

Use [decision rights](../decision-rights/core.md) for disputed authority. Carry an
existing settlement forward; a rephrased objection is not a changed premise.

Return the proposed next responsibility, justified commitment or reopening,
material evidence/owner-decision needs and affected support. Check completion
against supplied current Done receipts, distinguishing implementation, checks,
publication, delivery and observed outcome. Do not report DONE merely because
work was produced. Only the shell can record an event or report a live receipt.
