# Humanize

Read the [core](core.md) and the selected style references. Gather the actual
prose, voice sample, genre and requested mode. Preserve file frontmatter, code,
links, quotations and other non-prose content while materializing the input.

Apply the core and return its rewrite or critique. Resolve missing facts only
when needed to preserve meaning; never invent specificity for style. In direct
or embedded use, deliver the requested prose without a process transcript.

For an authorized file edit, apply the proposed replacement, reread the stored
result and check the protected facts and structures against the original. For
review-only requests, return findings without writes. State substantive gaps
instead of silently editing through them. Publication requires its own request.
