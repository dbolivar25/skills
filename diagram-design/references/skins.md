# Choose a skin

The representation owns meaning; the skin owns color, typography, and surface
material. Choose the actual project/client identity from current context before
applying a palette. A grid, shadow, radius, or favored font is not a universal
law for diagrams.

- **Augment:** read the [Augment skin](style-guide.md) and
  [Augment Design](../../augment-design/SKILL.md). The official logos, fonts,
  color roles, composition, voice, privacy, and relevant surface floor govern
  Augment work. Preserve the explicitly documented dark-surface adaptation.
- **An existing client/project:** resolve its `.diagram-design` marker and named
  profile using [profiles](profiles.md). Read the selected full guide directly;
  marker-based generation must not overwrite the shared installed guide.
- **A requested new skin:** use [onboarding](onboarding.md) to extract actual
  tokens/families from a URL, installed skill, folder, or supplied tokens. Keep
  uncertain mappings visible. Only write shared guide/profile/marker changes
  within the requested scope; ordinary generation can use tokens in the artifact.
- **Unbranded work:** use a suitable neutral treatment, for example the
  [neutral recipe](neutral-skin.md). Do not apply Augment merely because its
  skin is packaged here. Choose familiar native/plotting defaults when useful.

The retained gallery is a library of layout and encoding examples. Most files
use an earlier editorial skin with Geist and Instrument Serif. Those files are
references, not current brand-compliance receipts; copy their useful geometry
and apply the selected skin. Templates and primitive variants are optional:
[light](../assets/template.html), [dark](../assets/template-dark.html),
[editorial](../assets/template-full.html), [terminal](primitive-terminal.md),
[sketchy](primitive-sketchy.md), [annotations](primitive-annotation.md), and
[icons](primitive-icons.md). Do not let a full editorial template force a heading,
summary-card layout, or eyebrow the requested surface does not need.

Check actual rendered type, text wrapping, contrast, legend meanings, light/dark
polarity, and the intended export's font handling. A token name does not prove a
font loaded or a mark is visible. Exact brand assets remain packaged under
`assets/fonts/`; for Augment marks use the official Augment Design SVGs.
