# Slopegraphs

Use this for change between two comparable states. Each item connects its first and second value on two parallel axes with the same scale and units. The slope shows signed change across this particular interval; it does not show what happened between endpoints or establish speed without a meaningful shared duration.

Use the full relevant population or name the selection. Preserve item identity on both sides. A visible axis or clearly stated bounds prevents a narrowed range from exaggerating an otherwise small difference. If a transformation is used, apply it consistently and label it.

Compute both endpoint coordinates from one scale function. Labels may move with leaders to avoid collisions; the measured endpoints may not. Exact ties can share a coordinate while retaining every item's identity. Close values need smaller marks, grouped labels, or more space, not manufactured separation. Crossings are real comparisons, not routing defects to eliminate by changing values.

When one endpoint is missing, show the known value and the missing status or explicitly account for exclusion. Missing is different from no change. A focal series can be emphasized without suppressing others or changing their scale.

Verify against an independent table of source values, endpoint coordinates, and signed deltas. Check both sides and ties at the final size. There is no packaged automated slopegraph encoding validator; optional data attributes support manual or task-specific checks only.
