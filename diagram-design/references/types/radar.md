# Radar comparisons

Use this for several items scored across the same criteria when the pattern across criteria matters. A table or aligned dot plots often gives more precise comparison.

Define each criterion, score source, direction, and normalization. Criteria can have different original units only when their conversion to the displayed scale is explicit. Apply the same mapping for a criterion to every compared item. A subjective rating must retain its basis and uncertainty.

Each spoke uses a zero baseline and a common displayed scale. Place values at their true radial coordinates. Category order changes polygon shape and area, so keep it stable across comparisons and do not interpret polygon area as a total score. Connecting spokes suggests a profile, not measured values between criteria.

Keep series identifiable with outlines, marks, labels, and a clear legend. Too many series or spokes may need small multiples or another form. Missing scores create an explicit incomplete profile; they are not zero and must not be silently interpolated into a closed polygon.

Verify normalization, criterion directions, coordinates, missing scores, and legend identity from source data. Inspect overlaps and labels at delivery size. Use a palette suitable to the chosen skin rather than assuming the gallery palette is universal.
