# Radial quantity plots

Use a radial form when cyclic ordering or a circular comparison helps the actual question. For ordinary category magnitudes, a bar chart is usually easier to compare. This method covers radial lollipops, not every chart that happens to be circular.

For a radial lollipop, radius is proportional to a nonnegative value from a zero center: r = R·v/max. Do not add a decorative inner offset that makes zero look positive. Concentric reference rings use the same scale. Filled wedges encode area as well as radius and require a different, explicit encoding; they must not be substituted casually for length marks.

Place categories in their meaningful cyclic order when there is one. Equal angular spacing is a layout choice, not evidence of equal elapsed time. Label values and units. Unknown values have a missing-status mark or gap, never an invented zero ray. Signed quantities need a separately designed and explained form.

Calculate radii and ring values from source data. Check coordinates, scale, zero, missing, and maximum values independently. There is no packaged radial semantic validator or element allowlist that proves the figure correct. Inspect inner labels, crowded outer labels, and the final export.
