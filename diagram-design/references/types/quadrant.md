# Quadrants and scenario matrices

Use a quadrant for two independent dimensions, or a 2×2 scenario matrix for two uncertain drivers and four possible combinations. State which job the artifact does.

For quantitative axes, plot actual x and y values with units, scale, and threshold definitions. Points exactly on a boundary need a declared assignment rule when quadrants determine decisions. Never move a point to make it look more clearly inside a region. Unknown or uncertain positions remain explicit.

For qualitative positioning, name both ends of each dimension and explain the judgment basis. Placement is an assessment, not a measurement. Use concise labels, but keep units and enough axis explanation to prevent reversed interpretation.

A scenario matrix names four internally coherent possible worlds. It does not automatically rank them or select a preferred future. Recommendations or bets belong to a separate, supported interpretation. Use selected skin typography and emphasis rather than prescribing a particular editorial font.

Check axis independence, directions, thresholds, source positions, and scenario consistency. Inspect boundary cases, quadrant labels, crowded points, and any uncertainty at final size.
