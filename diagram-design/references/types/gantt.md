# Gantt schedules

Use this for activities with scheduled or actual start and end times. Use a timeline for point events and milestones when duration is incidental.

Use one real time scale. Record timezone, calendar convention, and whether end dates are inclusive when these affect duration. Derive bar position and length from start and end values. A milestone is a point or explicit marker, not a short task bar with invented duration.

Distinguish scheduled, actual, forecast, and uncertain dates. Unknown dates are not zero-duration work. Show uncertainty as a range or separate status when it matters. Dependencies, parallel work, resource constraints, and completion state appear only when supported; vertical ordering alone does not prove a dependency.

If tasks are grouped or summarized, keep the mapping and avoid implying a group's duration is the sum of parallel child durations. For a broad view, aggregate by a meaningful work package and disclose detail rather than applying an arbitrary task count limit.

Check dates, durations, dependencies, and milestone positions independently. Inspect short tasks, overlapping labels, month boundaries, current-time markers, and the export at delivery size.
