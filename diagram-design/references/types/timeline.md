# Timelines

Use this for events placed in time. Position events by their actual dates or timestamps; unequal intervals need unequal spacing unless the view explicitly uses ordinal order.

Show intervals as intervals and milestones as points. Label the time scale, timezone, and any axis breaks that affect interpretation. Distinguish observed, scheduled, proposed, and uncertain dates. Unknown timing is not the start of the axis. Keep concurrent events concurrent rather than manufacturing a clean sequence.

Check source dates and coordinate placement independently. Inspect overlapping events, long labels, interval boundaries, uncertainty ranges, and the delivered size. Use Gantt when task durations and dependencies are the main question.
