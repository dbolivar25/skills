# Neutral diagram recipe

An optional unbranded treatment, not a brand floor or universal aesthetic rule.
Use a different treatment when the data, medium, or audience needs it.

| Role | Light | Dark |
| --- | --- | --- |
| paper | `#ffffff` | `#17191d` |
| ink | `#20242a` | `#f5f6f8` |
| muted | `#545d6a` | `#bcc4cf` |
| rule | `#b8c0ca` | `#626d7c` |
| emphasis | `#315ba1` | `#a3c3ff` |

Use a readable system sans family for human names and an available system mono
for technical identifiers. Choose type size from the destination; do not shrink
labels to fit a dense canvas. Use direct labels, shape, or line style alongside
color. Prefer flat paper when decorative texture adds no meaning. Borders,
shadows, and corners can follow the actual surface grammar. Verify the selected
colors' contrast and the rendered font fallback rather than assuming this table
certifies every use.
