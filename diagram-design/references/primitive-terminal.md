# Terminal-style diagrams

Use this only when the task calls for a terminal or code-like visual treatment. The bundled [terminal template](../assets/template-terminal.html) is an illustrative skin, not a universal brand preset.

Monospace text, high-contrast surfaces, simple borders, and concise labels can evoke a terminal. Apply the selected brand's authorized roles when the result must be branded, or make the alternate skin choice explicit. Do not inherit a fixed orange accent or black background merely from the template.

ASCII or SVG structure still needs correct relationships and readable labels. A decorative prompt is not an executable command. If showing real commands, verify their syntax and distinguish them from example output. There is no packaged diagram-design render command; use the actual import scripts and export method.

Check line wrapping, ambiguous glyphs, screen and print contrast, source fidelity, and the artifact in its destination. Terminal styling does not remove accessibility or export requirements.
