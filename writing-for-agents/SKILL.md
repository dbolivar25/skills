# Writing for agents

Read the [core](core.md) and skill mechanics when packaging is involved. Acquire
the actual instructions, their callers, applicable repository guidance and the
current host/configuration facts. Identify the behavior the change should cause
before editing wording. Reuse established constraints and exact exclusions.

Apply the core to propose the structure, invocation contract and instructions.
Resolve its evidence needs from files, call sites and relevant prior results.
When behavioral verification is warranted, use evaluation-design, run the
comparison within the task's scope, and return its observations to the core.

Apply authorized changes with all affected callers and required references.
Run the repository's relevant metadata/link checks and any selected behavior
checks. Re-read the stored artifact and report what was actually verified.
Structural validity is not a behavioral improvement receipt. Installed catalog
reload, packaging and publication are distinct effects and must be requested.
