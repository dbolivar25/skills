## Ideas and context cut

These are substantive changes, not just relocation:

- Extra TDD or framing approval gates after work is already authorized; compulsory alternative exploration for a settled design; fixed architecture inventory forms, candidate caps and report labels.
- Universal module-shape, dependency-injection, glossary-length, synonym and file-order prescriptions. Their concrete examples and ownership reasoning remain.
- Compulsory AI report templates and role labels, repeated unchanged interview paperwork, and evaluation layers invented only to complete a form. Semantic coverage remains required.
- UI numeric laws, fixed axes for creative range, automatic ornament and blanket 44px rules for every control. Actual access, focus, contrast, state and reduced-motion requirements remain.
- Brand bans that hid relevant uncertainty, evidence or useful production disclosures; the claim that regular prose rhythm proves machine authorship; a ban on repeating a fact even when navigation requires it.
- Creative output-count quotas, forced practical derivatives, familiar-category bans and adoption rosters used as authority. The named operations, teaching examples, counterexamples and cultural character remain.
- Unsupported example measurements and causal claims; inaccurate coffee, termite, mycelium and compression-progress accounts. Revised examples distinguish illustration, analogy and measured evidence.
- Duplicate routing mood lists and optional method-pair examples. All method routes, close-route distinctions and meaningful sequence examples remain; this also keeps the full creative package within the existing publisher limit.
- Diagram sample counts, positions and styles as universal semantic requirements; fabricated missing journey sentiment; and claims that imaginary validators prove an encoding. Correctness is checked against the actual source and helper coverage.
- Automatic client-profile copying over the installed diagram guide. Selected task or project profiles remain usable without altering the shared guide.
- Cached CLI/vendor details that the current installed tool or official documentation can establish more accurately.
