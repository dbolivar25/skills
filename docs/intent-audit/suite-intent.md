## Working conclusions to challenge

The suite contains different kinds of useful material: domain judgment, authoring pedagogy, process, operational adapters, artifact rendering, and host mechanics. Similar words such as “evidence,” “scope,” “seam,” and “preserve” do not establish duplicate responsibility.

The strongest currently supported changes are at specific seams: stale callers, contradictory examples, unclear precedence, and repeated operational contracts. Retire STE and Herdr under owner direction. Additional broad retirement or replacement by generic principles is not yet earned. A no-op claim still requires a relevant comparison; neither a static validator nor this source reading establishes model behavior.

Baseline structural validation currently fails because decision-rights has no invocation case. The existing corpus explicitly contains expectations, not recorded model results. Treat that limitation as part of validation design.
