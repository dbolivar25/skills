## Disclosed cuts

### The shared core/operational-caller composition protocol and generic status envelopes

Retained: The actual method, factual gaps, meaningful uncertainty, and ordinary authority boundaries. Steward's actual runtime event/review contracts remain exact.

Loss: Supplied-only conceptual assessment interfaces become less directly selectable; read-only judgment remains an available job.

### 21 fewer public selection boundaries

Retained: 15 complete-job interfaces plus selectively read private methods. Architecture/spec are flat engineering jobs; evaluation remains independent.

Loss: 26 old public skill names disappear, five new names are introduced, and ten names remain. Their retained jobs must be discoverable through natural prompts. Branch instructions cannot enforce the old architecture/spec per-skill metadata policy; actual host routing must be tested.

### Global engineering checklist, public-JSDoc accounting, universal failure-algebra mandate and categorical mocking/spy bans

Retained: Precise values, expected failures, owned effects, TypeScript soundness, independent oracles and actual-boundary evidence where applicable.

Loss: These are substantive relaxed prescriptions, not mere repackaging. Broad consistency law is traded for task/repository-grounded judgment.

### Fixed hypothesis counts and local-red/minimization prerequisites

Retained: Strong symptom signal, reproduction adequacy, falsifiable alternatives and discriminating observations.

Loss: A universal laboratory-shaped process no longer gates production-only diagnosis.

### Automatic spec TDD, prototype no-tests rule, and mandatory three radical UI variants

Retained: Selected vertical-slice TDD, necessary tests, meaningful range for open taste, and cheapest credible question-driven prototype.

Loss: A fixed process/variant count no longer guarantees breadth or discipline; observed evidence must establish adequacy.

### Uncalibrated prose score, detector thresholds, universal novelty/proper-noun quotas, and mandatory grounded derivatives for fiction

Retained: Actual voice examples, conservative meaning protection, concrete artistic method and specificity.

Loss: Numeric ceremony and forced practicality disappear; no claim that all odd language is AI language.

### Universal diagram grid/shadow/corner law and NatStat-only product kits

Retained: All useful semantic forms and import/export methods; brand-specific laws apply only to that brand. Unknown remains distinct from denied/false/zero.

Loss: Product-specific NatStat aesthetics/context archived outside active references after reusable semantics are extracted.

### Historical maintenance ledgers and old audit narratives from the active learning path

Retained: Recoverable repository history, indispensable lessons and examples, old Steward record intelligibility.

Loss: Agents will no longer receive the full history of how each instruction was written unless that history matters to the task.

### TypeSafe as a default standalone AI proposition

Retained: Vendor knowledge and license, live docs when selected, typed inference and calibrated probability principles independent of vendor.

Loss: Automatic vendor promotion/discovery is removed; the vendor is chosen for the actual job.
