# Understand a change

Read the [core](core.md). Establish the consumer's question and actual source:
local diff, proposal, work product or supplied comparison. Resolve prior state
and intent from the task and governing documents. Gather enough surrounding
source to explain material behavior rather than relying on author summaries.

For live PRs, read [PR operations](../github-evidence/references/pr-operations.md)
and use GitHub evidence where its helpers are needed. Record actual base/head,
discussion context and validation receipts. A local comparison remains useful
when live state is unavailable; label that limit rather than calling it current.

Apply the core and resolve its named source gaps. Reuse a current map, refreshing
only changed premises and regions while keeping complete coverage. Return the
map, evidence and uncertainty. Understanding alone selects neither a verdict nor
review writing and requires no invented acceptance decision.
